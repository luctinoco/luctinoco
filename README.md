## 🚀 Tecnologias e Ferramentas

### 🐍 Python

> Ferramentas para manipulação de dados, aprendizado de máquina, visualização interativa e automação de análises:

- `pandas`, `numpy` – Manipulação e estruturação de dados
- `matplotlib`, `seaborn`, `plotly` – Visualização estática e interativa
- `scikit-learn` – Modelagem preditiva e pipelines de machine learning
- `shap` – Explicabilidade de modelos
- `dash` – Desenvolvimento de dashboards analíticos interativos

### 📊 R

> Pacotes para ciência de dados, estatística aplicada, limpeza e análise geoespacial:

- `tidyverse` – Conjunto de pacotes para manipulação, modelagem e visualização de dados
- `dplyr`, `tidyr`, `janitor` – Transformação, limpeza e organização de dados
- `ggplot2`, `plotly` – Visualização gráfica avançada
- `lubridate` – Manipulação de datas e séries temporais
- `caret` – Treinamento e validação de modelos preditivos
- `sf` – Análise espacial com dados vetoriais georreferenciados

### 🛠️ Ferramentas complementares

- **SQL** – Consultas complexas, criação de views e integração com BI
- **Power BI** – Desenvolvimento de dashboards interativos
- **Excel** – Análises rápidas, suporte a BI e validação
- **QGIS** – Geoprocessamento com dados raster e vetoriais
- **Bash & Linux** – Automação de scripts, controle de processos em HPC
- **Git & GitHub** – Controle de versão e colaboração em projetos

## 📁 Projetos em destaque

🔗 [Teias Vivas](https://github.com/luctinoco/Teias_Vivas)  
Script em Python para análise de redes ecológicas, combinando dados de planilhas com métricas de centralidade e detecção de comunidades.

🔗 [Caipora](https://github.com/luctinoco/Caipora)  
Ferramenta interativa em Python para análise de métricas de paisagem a partir de dados raster, com visualizações em mapas e gráficos.

🔗 [TrypPredictor](https://github.com/luctinoco/TrypPredictor)  
Modelo de machine learning com Gradient Boosting aplicado à predição de infecção por *T. cruzi*, com técnicas de explicabilidade e seleção de variáveis.

🔗 [FieldToLab](https://github.com/luctinoco/FieldToLab)  
Projeto fullstack (Flask + JS) para gerenciar e processar dados de campo e laboratório com automação de rotinas e interface web.

🔗 [Metrics Extraction and Analysis for Ecological Data](https://github.com/luctinoco/Metrics-Extraction-and-Analysis-for-Ecological-Data)  
Scripts em R e Python para extração de métricas ecológicas, com foco em automação e análises multiescalares.

🔗 [3D Heart Animation](https://github.com/luctinoco/3D_Heart_Animation)  
Projeto educacional com visualização animada em 3D de um coração, utilizando Python para fins didáticos e ensino de lógica.
